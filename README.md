# 몸소 깨닫는 불법도박의 실체

중·고등학생이 **가상 머니로 불법 도박 사이트를 직접 겪어 보고**, 딴 돈을 왜 받을 수 없는지 스스로 찾아내는 체험형 불법도박 예방교육 프로그램입니다.

**바로 체험하기 → https://casino-prd.vercel.app**

설치·회원가입·로그인 없이 휴대폰이나 PC 브라우저로 열면 됩니다.

> 체험 속 금액은 모두 가상 머니입니다. 실제 결제·계좌·개인정보 입력은 없고, 실제 도박 사이트로 연결되는 링크도 없습니다.

## 학습 목표

1. **안다** — 불법 도박 사이트는 이기고 지는 결과를 운영자가 정한다는 것을 안다.
2. **찾는다** — 돈을 따도 받을 수 없게 만드는 수법을 체험 속에서 찾아낸다.
3. **실천한다** — 권유를 받았을 때 거절하고, 필요하면 도움을 요청한다.

## 수업 흐름 (45분)

| 단계 | 시간 | 하는 일 |
|---|---|---|
| 도입 | 5분 | 프로그램 소개를 끝까지 읽고 시작 |
| 1. 체험 | 10분 | 가상 머니 100,000원으로 게임 4종(룰렛·주사위 홀짝·경마·슬롯머신) 체험 |
| 2. 수법 찾기 | 5분 | 체험 중 수상했던 장면을 직접 고르기 |

체험은 미리 정해진 각본대로 흘러갑니다. 처음 몇 판은 돈이 불어나다가, 5판을 채워 출금을 누르면 출금이 되는 듯하다가 "인터넷 오류"와 함께 사이트가 사라집니다. **학생이 실제로 받은 돈은 0원**입니다.

## 체험 속에 숨어 있는 수법

처음엔 이기게 해 주기 · 아깝게 진 것처럼 보이기 · 가짜 당첨 소식 · 출금 조건 걸기 · 시간에 쫓기게 하기 · 가입할 때 개인정보·계좌 요구 · 친구 초대 보상 · 판돈 키우게 하기 · 출금하면 사이트 닫고 도망가기

모든 설명은 **피해자 시점**(무엇을 겪고, 왜 돈을 찾을 수 없는가)으로만 썼습니다.

## 안전하게 운영하기 위한 원칙

- **실제 돈·개인정보를 쓰지 않습니다.** 가입 체험 화면의 이름·계좌·신분증 칸은 입력되지 않게 막혀 있습니다.
- **기록을 밖으로 보내지 않습니다.** 서버·로그인·분석 스크립트가 없습니다. 진행 상황은 그 브라우저 탭 안에만 저장되고, 탭을 닫으면 지워집니다(공용 기기 대비).
- **반드시 정답을 공개합니다.** 체험이 어떻게 끝나든 수법 공개와 상담 안내로 이어집니다.
- **반복할 이유를 만들지 않습니다.** 점수·순위·보상·칩 이월이 없고, 누구나 같은 결과로 끝납니다.
- **실제 사이트를 흉내 내지 않습니다.** 실제 사이트 이름·로고·배당률을 쓰지 않았고, 체험 중에는 "체험용 · 실제 돈 아님"이 늘 보입니다.
- **도움이 먼저인 학생을 챙깁니다.** 도박 경험이 있는 학생에게는 자가진단(9문항)과 상담을 먼저 안내합니다.

## 직접 실행하기 (개발자용)

React 19 + Vite로 만든 정적 웹앱입니다. 서버나 데이터베이스가 필요 없습니다.

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 폴더에 배포용 파일 생성
```

```
src/
├─ App.jsx               메뉴·화면 전환, 진행 상황 저장(sessionStorage)
├─ HomeScreen.jsx        첫 화면(프로그램 소개)
├─ questions.js          자가진단 문항
└─ experience/
   ├─ scenario.js        체험 각본(판마다 결과·판돈), 수법·퀴즈 문구
   ├─ Experience.jsx     체험 단계(가입→게임→출금→수법 찾기→정답 공개→마무리)
   └─ Games.jsx          룰렛·주사위 홀짝·경마·슬롯머신
```

체험 결과는 [`src/experience/scenario.js`](src/experience/scenario.js)에서 미리 정해집니다. 실제 확률이나 배당 계산은 없습니다.
