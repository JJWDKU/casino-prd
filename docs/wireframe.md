## 1. 진단 화면
```
┌───────────────────────────┐
│ 멈춤 노트          [도움] │
│ 지난 12개월을 떠올려 보세요 │
│ Q1 ... ○전혀 ○가끔 ○자주 ○거의 항상 │
│ ... (9문항)               │
│ [결과 보기]               │
├───────────────────────────┤
│ 결과: 주의 (참고용)        │
│ 다음 행동: 이번 주 기록 시작 │
│ [기록하러 가기] [1336 전화] │
└───────────────────────────┘
```

```
┌───────────────────────────┐

│ 상황 (●충동만 ○실제 베팅)   │

삭제 클릭 → [정말 삭제] [취소]
```

## 3. 도움 화면
```
┌───────────────────────────┐
│ 지금 힘들다면              │
│ [📞 1336 전화하기 (24시간)] │
│ 한국도박문제예방치유원 →    │
│ 지금 할 일: 앱 지우기 / 계좌 │
│ 맡기기 / 한 사람에게 말하기 │
└───────────────────────────┘
```

## 화면별 정리
| 화면 | 입력·버튼 | 누른 뒤 결과 | 실패·미확인 조건 | 연결할 Q6 |
|---|---|---|---|---|
| 진단 | 9문항, [결과 보기] | 위험 수준 + 1336 버튼 | 미응답 문항 있으면 안내 (AC-08) | Q6-1 |
| 기록 | 입력 4칸, [기록 추가], [삭제] | 목록·합계 갱신 | 금액 빈칸(AC-04), 삭제 취소(AC-05) | Q6-2, Q6-3 |
| 도움 | [1336 전화하기] | 전화 앱 열림 | PC에서는 번호만 보임 [가설] | Q6-4 |
