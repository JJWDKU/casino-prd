# 와이어프레임 (v3 · 학교 예방교육용) — 몸소 깨닫는 불법도박의 실체

흐름: 시작 → ① 가입(T7) → ② 게임 고르기(T2·T4·T8) → ③ 게임 진행(G1~G5, 15판) → ④ 판 뒤집기 → ⑤ 수업 마무리
모든 체험 화면(①~③) 상단: `⚠ 체험용 · 실제 돈 아님` 고정

## 0. 시작 화면
```
┌───────────────────────────┐
│ 몸소 깨닫는 불법도박의 실체 [도움] │
│ 운영자들이 쓰는 수법을      │
│ 가상 칩으로 직접 당해 보세요. │
│ 실제 돈·개인정보는 쓰지 않아요. │
│ Q. 불법 도박으로 돈을 벌 수  │
│    있다고 생각하나요?       │
│ ○그렇다 ○모르겠다 ○아니다   │
│ [체험 시작]                │
│ [체험 대신 도움 받기]       │
└───────────────────────────┘
```

## 2. 게임 고르기 (T2·T4·T8)
```
┌───────────────────────────┐
│ ⚠ 체험용 · 실제 돈 아님      │
│ 보유 칩 100,000   0/15판   │
│ ┌ 첫 충전 보너스 +50,000 ┐ │ ← T2·T6
│ └ 종료까지 00:59 [받기] ─┘ │
│ [G1 카드] [G2 홀짝]        │
│ [G3 로켓] [G4 돌림판]       │
│ [G5 가상 축구]             │
│ 실시간: 김**님 300만 당첨   │ ← T4
│ [출금하기]                 │ ← T5
└───────────────────────────┘
5판째에 팝업: "친구 1명 초대하면 30,000 칩
 내 코드 LUCKY-7Q2"  [초대하기] [초대하지 않기]  ← T8
```

## 화면별 정리
| 화면 | 입력·버튼 | 누른 뒤 결과 | 실패·미확인 조건 | 연결할 Q6 / AC |
|---|---|---|---|---|
| 시작 | 전 질문, [체험 시작], [도움 받기] | 가입 / 도움 | 미응답 시 시작 안 됨 [가설] | Q6-4 |
| 가입 | 막힌 입력칸, [입력 없이 가입] | 게임 고르기 | 입력 시도 → 안내 (AC-19) | Q6-1 |
| 게임 고르기 | G1~G5, [받기], [출금하기] | 게임 진행 / 거부 | 초대 팝업 거절 (AC-20) | Q6-1, Q6-2 |
| 게임 진행 | 게임별 선택, [게임 바꾸기] | 칩 증감 | 15판 끝 → 판 뒤집기 (AC-13) | Q6-1 |
| 판 뒤집기 | [1336], [1388], [마무리], [기록 지우기] | 전화 / 마무리 / 삭제 | 체험 없이 들어오면 "체험 먼저" [가설] | Q6-3, AC-22 |
| 수업 마무리 | 토론 질문, 진행 안내 펼치기 | 안내 펼침 | PC에서는 번호만 보임 | Q6-5 |
