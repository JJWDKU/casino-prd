# 5칸 구조도

| Q4 기능 | Q5 화면 | 입력 | 처리 | 출력 |
|---|---|---|---|---|
| 자가진단 | 진단 화면 | 9문항 응답(0–3점) | 점수 합산 → 위험 수준 판정 | 위험 수준·다음 행동·1336 버튼 |
| 기록 등록 | 기록 화면 | 날짜·금액·상황·메모 | 새 기록 생성 → localStorage 저장 | 목록 맨 위 표시, 이번 달 합계 |
| 기록 삭제 | 기록 화면 | [삭제] → 확인/취소 | 확인 시 해당 기록 제거 → 저장 | 개수·합계 감소 (취소 시 유지) |
| 도움 찾기 | 도움 화면 | 하단 [도움] 탭 | 고정 안내 읽기 | 1336 전화 링크, 기관 링크 |

## 저장 구조 [가설]
- localStorage 키 `stopnote.records` : `[{ id, date, amount, type: "urge" | "bet", memo }]`
- 진단 결과는 저장하지 않음 (민감 정보 최소화) [가설]

## 질문
- 저장 위치: 브라우저만 쓰면 기기를 바꾸면 기록이 사라진다. 괜찮은가?
- 권한: 로그인 없음 — 같은 폰을 가족이 보면 기록이 보인다. 잠금(PIN)이 필요한가?
- API·DB: 이번 범위에서는 없음.
- 실패 조건: localStorage가 막힌 브라우저(시크릿 모드 등)에서는 안내 문구를 보여 준다.
